# Mes cours bien rangés · OCTET

Parcours S1 (formation numérique, champ « Informations et données ») : découvrir l'explorateur de fichiers et OneDrive, puis construire sa vraie arborescence `COURS S1` et y ranger une fiche.

| Fichier | Rôle |
| --- | --- |
| `comprendre.html` | J'apprends : « Comment mes fichiers sont rangés » (8 modules + 6 défis) |
| `index.html` | Je pratique : « Mes cours bien rangés » (6 missions + bonus) |
| `css/ranger.css` · `js/ranger.js` | Styles communs (charte OCTET) et interactions du parcours pratique |
| `css/comprendre.css` · `js/comprendre.js` | Compléments de styles et interactions du volet J'apprends |
| `note-enseignant-comprendre.html` | Note enseignant du volet J'apprends |
| `fichiers/Les_etats_de_la_matiere.pdf` | Fiche à ranger dans Sciences › Physique (missions 5-6) |
| `fichiers/Mesurer_un_angle.pdf` | Fiche bonus, à ranger dans Math |
| `fiche-enseignant.html` | Fiche pédagogique imprimable (durée, référentiel, critères de réussite) |

- Aucune dépendance, aucun envoi de données. Progression dans `localStorage` (clés `octet-cours-ranges-v1` et `octet-comprendre-v1`). Chaque module J'apprends s'ouvre directement : `comprendre.html#fichier`, `#sous-dossier`, `#arborescence`, `#chemin`, `#explorateur`, `#local`, `#synchro`, `#copier`, `#defis`.
- Les polices viennent de Google Fonts, comme les autres ressources du dépôt (avec repli local).
- Le lien « OCTET · Mes cours bien rangés » en haut renvoie vers `../index.html#informations-donnees`.
