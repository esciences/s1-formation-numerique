# Mes cours bien rangés · OCTET

Parcours S1 (formation numérique, champ « Informations et données ») : découvrir l'explorateur de fichiers et OneDrive, puis construire sa vraie arborescence `COURS S1` et y ranger une fiche.

| Fichier | Rôle |
| --- | --- |
| `index.html` | L'application (6 missions + bonus) |
| `css/ranger.css` · `js/ranger.js` | Styles (charte OCTET) et interactions |
| `fichiers/Les_etats_de_la_matiere.pdf` | Fiche à ranger dans Sciences › Physique (missions 5-6) |
| `fichiers/Mesurer_un_angle.pdf` | Fiche bonus, à ranger dans Math |
| `fiche-enseignant.html` | Fiche pédagogique imprimable (durée, référentiel, critères de réussite) |

- Aucune dépendance, aucun envoi de données. Progression dans `localStorage` (clé `octet-cours-ranges-v1`).
- Les polices viennent de Google Fonts, comme les autres ressources du dépôt (avec repli local).
- Le lien « OCTET · Mes cours bien rangés » en haut renvoie vers `../index.html#informations-donnees`.
