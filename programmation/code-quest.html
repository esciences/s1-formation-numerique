Code Quest

Tu as découvert comment parler à une machine. Prouve maintenant que tu maîtrises les briques de la programmation !

Chaque niveau réussi ajoute 1 à ta variable briques et ouvre le niveau suivant. Quand briques vaut 8, le défi final ★ s’ouvre. Réussis-le pour découvrir le mot secret à donner à ton professeur. Ta progression reste sur cet ordinateur.

Ta quête

Niveau 1 · Algorithme

Remets les étapes dans l’ordre

Référentiel P5

Un algorithme, c’est une suite d’étapes dans un ordre précis. Clique sur les étapes dans le bon ordre. Clique sur une étape placée pour la retirer. Réussis les 2 algorithmes.

Étapes mélangées
La première étape, c’est celle qu’on ne peut faire qu’au tout début.
Niveau 2 · Algorithme ≠ programme

Humain ou machine ?

Référentiel P6

L’algorithme est écrit pour un humain (en français ou dessiné). Le programme est écrit pour une machine, dans un langage de programmation. Classe les 6 cartes.

Attention : les blocs aussi sont un langage de programmation.
Niveau 3 · Logigramme

Choisis la bonne forme

Référentiel P5

Dans un logigramme, chaque forme a un rôle. Pour chaque élément, choisis sa forme.

Une question qui se répond par oui ou non, c’est une décision.
Niveau 4 · Séquence

Programme le robot

Référentiel P5

Écris la suite d’instructions qui amène le robot jusqu’à l’étoile sans toucher un mur, puis exécute-la. Réussis les 2 missions.

Ton programme
Le robot exécute les instructions une par une, dans l’ordre.
Niveau 5 · Boucle

Raccourcis avec une boucle

Référentiel P6

Repère ce qui se répète et complète la boucle. Pour les deux dernières situations, choisis le bon type de boucle.

Compte combien de fois le motif revient.
Niveau 6 · Condition

Que fait le programme ?

Référentiel P6

Lis chaque programme et la situation, puis choisis ce que fait la machine. Réponds aux 4 situations.

La condition est vraie ? On fait « alors ». Elle est fausse ? On fait « sinon ».
Niveau 7 · Variable

Suis la valeur dans la boîte

Référentiel S1

Lis les programmes ligne par ligne et écris la valeur de la variable. Dans le dernier programme, écris aussi combien de bougies sont soufflées. score ← score + 2 se lit : « prends score, ajoute 2, range le résultat dans score ».

Programme B · les bougies
