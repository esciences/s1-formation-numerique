Algorithme ≠ programme

Même idée, deux façons de l'écrire

Algorithme

  • écrit pour un humain
  • en français, avec des mots ou un dessin (logigramme)
Tant qu'il reste des bougies allumées,
souffle une bougie.

Programme

  • écrit pour une machine
  • traduit dans un langage de programmation
while bougies > 0:
    souffler()

Le programme, c'est l'algorithme traduit pour que l'ordinateur puisse l'exécuter.

0
score

Une boîte avec une étiquette

nomL'étiquette sur la boîte : score, vies, temps…
valeurCe qu'il y a dans la boîte maintenant (un nombre, un mot…).
changeLe programme peut lire la valeur et la remplacer par une autre.
score ← score + 1

Se lit : « Prends la valeur de score, ajoute 1, et range le résultat dans score. »
